厄年早見表 2026年・2027年

よくある質問

厄年の数え方は地域で違いますか？
数え年の基準日を元日とするのが一般的ですが、立春を基準にする寺社もあります。厄払いを受ける予定の寺社の表記に合わせるのが確実です。
厄払いはいつ行けばいいですか？
年明けから節分までに行く方が多いですが、一年中受け付けている寺社がほとんどです。
早生まれの場合はどうなりますか？
数え年は生まれた「年」だけで決まるため、早生まれかどうかは関係ありません。生まれ年の欄をそのまま見てください。
